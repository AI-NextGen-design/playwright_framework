# Code of Conduct

## Our commitment

We want participation in the Playwright Java Automation Framework community to be a respectful, welcoming and constructive experience for everyone.

## Expected behaviour

Community members are expected to:

- Be respectful and considerate.
- Welcome different levels of experience and perspectives.
- Give and receive constructive feedback gracefully.
- Focus on what is best for the project and its community.
- Communicate professionally in issues, pull requests and discussions.

## Unacceptable behaviour

Examples of unacceptable behaviour include:

- Harassment, intimidation or personal attacks.
- Discriminatory or degrading language.
- Trolling, insulting or deliberately disruptive comments.
- Publishing another person's private information without permission.
- Any other conduct that would reasonably be considered inappropriate in a professional community.

## Scope

This code of conduct applies in project spaces, including issues, pull requests, discussions and other community interactions associated with the project.

## Reporting

If you experience or witness unacceptable behaviour, contact the project maintainer privately through the contact method listed on the repository profile. Please include relevant context or links where possible.

The project maintainer will review reports fairly and take appropriate action. Reports will be handled with discretion to the extent practical.

## Enforcement

The project maintainer may remove, edit or reject comments, commits, issues and other contributions that violate this code of conduct, and may temporarily or permanently restrict participation where appropriate.

This Code of Conduct is adapted in spirit from the Contributor Covenant. It is intended as a practical community standard for this repository.
